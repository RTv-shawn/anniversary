# 我们的一周年 💕

Anniversary photo gallery website.

## How to deploy to GitHub Pages

1. Create a new repo on GitHub: https://github.com/new
2. Push this folder:

```bash
cd "H:\照片\website"
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git add .
git commit -m "Initial: anniversary gallery site"
git push -u origin main
```

3. Go to repo Settings > Pages > Source: "Deploy from a branch" > main > / (root) > Save
4. Your site will be at: `https://YOUR_USERNAME.github.io/YOUR_REPO/`

## Customize

Edit `index.html` to replace placeholder text with your names and messages.
